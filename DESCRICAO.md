# Arena Texas Hold'em Poker

## Descrição Breve

**Arena Texas Hold'em Poker** é um simulador educacional interativo de poker desenvolvido em Python/Pygame, projetado especificamente para ensinar conceitos de probabilidade e estatística de forma divertida e visual.

O programa permite que até 4 jogadores participem de rodadas completas de Texas Hold'em, enquanto acompanham em tempo real:
- Cálculos de probabilidade de vitória
- Análise de força de mãos
- Sistema de pontuação acumulativa
- Visualização clara de todas as combinações possíveis

## Objetivo Pedagógico

Transformar o aprendizado de matemática em uma experiência prática e envolvente, demonstrando como probabilidade, combinatória e estatística funcionam em situações reais e dinâmicas.

## Principais Recursos

✅ Interface gráfica amigável e responsiva  
✅ Cálculo automático de probabilidades  
✅ Suporte para 4 jogadores  
✅ Sistema completo de Texas Hold'em (Flop, Turn, River)  
✅ Visualização de todas as mãos e combinações  
✅ Ideal para uso educacional em sala de aula  

## Tecnologias

- Python 3.7+
- Pygame 2.0+

## Como Executar

```bash
pip install pygame
python main.py
```
